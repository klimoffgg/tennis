# Турнирная сетка: как запустить и как вести турнир

Сайт состоит из одного файла `index.html`. Данные он берёт из Google Таблицы и сам перестраивает сетку каждые 30 секунд. Пока таблица не подключена, показывается демо.

## 1. Таблица (один раз)

1. Создай **новую** Google Таблицу. Не используй таблицу с ответами формы: она станет доступна по ссылке, а там телеграмы и номера комнат.
2. Сделай два листа (вкладки внизу) с такими названиями, буква в букву:
   - **Участники**, в первой строке заголовки: `Посев` | `Имя`
   - **Матчи**, в первой строке заголовки: `Матч` | `Счёт`
3. «Настройки доступа» → «Все, у кого есть ссылка» → **Читатель**.
4. Скопируй ссылку на таблицу.

## 2. Подключить таблицу к сайту

В `index.html` найди блок `НАСТРОЙКИ` и вставь ссылку:

```js
SHEET: 'https://docs.google.com/spreadsheets/d/.....',
```

Открой `index.html` в браузере: вместо демо должна появиться твоя сетка (или пустая, если участников ещё нет).

## 3. Задеплоить на Vercel

Вариант А, через GitHub:
1. Создай репозиторий, закинь туда `index.html`.
2. vercel.com → Add New → Project → выбери репозиторий.
3. Framework Preset: **Other**, остальное не трогай → Deploy.

Вариант Б, из терминала в папке с `index.html`:
```
npx vercel --prod
```

После деплоя открой ссылку **с мобильного интернета без VPN**, лучше у пары людей с разными операторами. Если `*.vercel.app` тупит, залей тот же файл на GitHub Pages (Settings → Pages → Deploy from branch).

## 4. Перед турниром: участники и посев

- В лист **Участники** перенеси имена из ответов формы.
- **Посев**: сильнейшим ставь 1, 2, 3… (по вопросу про уровень: секционщики первыми). Остальным можно оставить пусто, они встанут после посеянных в порядке строк.
- Посеянные 1 и 2 окажутся в разных половинах сетки и встретятся только в финале. Если участников не 8/16/32, лишние места закрываются проходами, их получают верхние посевы.

**Важно:** после первого сыгранного матча список участников не меняй. Номера матчей считаются от списка, и при изменении они сдвинутся.

## 5. В день турнира

- На каждой карточке есть номер матча (№7 и т.д.). Оранжевая рамка = оба игрока известны, можно играть.
- Сыграли матч → в лист **Матчи** пишешь строку: `7` | `2:1`.
- **Первое число = игрок сверху в карточке**, второе = игрок снизу.
- Ошибся → просто исправь ячейку, сайт пересчитает всё дальше сам.
- Ничья или пустой счёт = матч считается не сыгранным.
- Неявка: ставь техническую победу `2:0` тому, кто пришёл.

Что сайт считает сам:
- кто проходит дальше по основной сетке;
- утешительную сетку за 5–8 места (проигравшие в четвертьфиналах) и матч за 5-е место;
- матч за 3-е место;
- итоговую пятёрку в сборную на Спартакиаду. После финала этот блок поднимается наверх страницы.
